# 📥 One-Click Image Downloader for Chrome

A lightweight, fast, and simple Google Chrome extension built with Manifest V3 that allows you to download all images from any webpage in a single click.

## ✨ Features
- **One-Click Action:** Instantly grabs all image sources (`<img>` elements) from the current active tab.
- **Fast & Lightweight:** No bloatware, clean vanilla JavaScript code.
- **Manifest V3 Compliant:** Fully up-to-date with modern Chrome extension standards.

## 🚀 How to Install (Developer Mode)
1. Download or clone this repository to your computer.
2. Open Google Chrome and navigate to `chrome://extensions`.
3. Enable **Developer mode** using the toggle in the top-right corner.
4. Click **Load unpacked** in the top-left and select the folder containing these extension files.
5. Click the extension icon on any webpage and hit "Download all images"!

## 🛠️ Built With
- HTML5 / CSS3
- JavaScript (Chrome Extensions API)
